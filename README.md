# OriginChain

**Own Your Creativity. Prove Your Origin.**

A decentralized creator identity and proof-of-origin platform built on Arbitrum. Creators register digital and physical works on-chain, generating verifiable proof of authorship, ownership, and timestamp.

## Status

🚧 Hackathon build in progress — Lampros DAO Hackathon.

## Documentation

Full architecture, API spec, database schema, and roadmap live in [`docs/`](./docs/DEVELOPER_KICKOFF_BLUEPRINT.md). Start there.

## Structure

This is a monorepo:

- `apps/` — frontend (Next.js) and backend (Express) applications
- `contracts/` — Arbitrum Stylus smart contracts (Rust)
- `packages/` — shared TypeScript types and config
- `docs/` — engineering documentation
- `scripts/` — operational/deployment scripts
